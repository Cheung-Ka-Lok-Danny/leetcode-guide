# 快速开始

欢迎来到 **LeetCode 算法题指南**！本指南旨在帮助你系统化地学习数据结构和算法，告别盲目刷题。

## 如何使用本指南

### 推荐学习路径

```
基础篇 → 核心篇 → 进阶篇 → 综合实战
```

### 基础篇（建议顺序）

1. **[数组与字符串](/topics/array-string/)** — 算法入门的第一关
2. **[链表](/topics/linked-list/)** — 指针操作的经典
3. **[栈与队列](/topics/stack-queue/)** — 线性结构的进阶
4. **[哈希表](/topics/hash-table/)** — 空间换时间的思想
5. **[排序与搜索](/topics/sorting-searching/)** — 算法效率的基石

### 核心篇（建议顺序）

6. **[树与二叉树](/topics/tree/)** — 递归思维的训练场
7. **[堆](/topics/heap/)** — 优先队列的精髓
8. **[双指针](/topics/two-pointers/)** — 巧妙的遍历技巧
9. **[滑动窗口](/topics/sliding-window/)** — 子数组问题的利器
10. **[回溯算法](/topics/backtracking/)** — 暴力搜索的艺术

### 进阶篇（建议顺序）

11. **[动态规划](/topics/dynamic-programming/)** — 面试的重中之重
12. **[贪心算法](/topics/greedy/)** — 局部最优到全局最优
13. **[图](/topics/graph/)** — 复杂关系的建模
14. **[并查集](/topics/union-find/)** — 连通性的高效解法

### 专项技巧

15. **[位运算](/topics/bit-manipulation/)** — 底层优化的利器
16. **[数学技巧](/topics/math/)** — 算法中的数学思维

## 难度等级说明

<span class="difficulty-easy">简单 Easy</span> — 基础题，适合新手入门
<span class="difficulty-medium">中等 Medium</span> — 核心题，面试高频

## 如何学习每个主题

每个主题页面包含以下内容：

1. **概念讲解** — 核心思想和原理
2. **常见题型** — 该类问题的典型模式
3. **例题精讲** — LeetCode 原题详解
4. **代码模板** — 可复用的解题框架
5. **复杂度分析** — 时空效率评估

> 💡 **建议**：先理解概念和模板，再独立完成配套的 LeetCode 题目，最后对照代码示例查漏补缺。
