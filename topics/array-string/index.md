# 数组与字符串

数组与字符串是最基础的数据结构，也是算法面试的入门必考内容。掌握数组和字符串的操作技巧，是解决更复杂问题的基础。

## 核心概念

- **数组**：连续内存空间存储相同类型元素的线性表
- **字符串**：字符数组的封装，具有特殊的操作 API
- **时间复杂度**：随机访问 O(1)，插入/删除 O(n)
- **空间复杂度**：O(n)

## 解题框架

```
数组/字符串问题 → 识别题型 → 选择算法 → 边界处理 → 优化
```

## 复杂度总览

| 技巧 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|---------|
| 遍历 | O(n) | O(1) | 查找、统计 |
| 前缀和 | O(n) 预处理 / O(1) 查询 | O(n) | 区间和查询 |
| 差分数组 | O(n) | O(n) | 区间批量更新 |
| 双指针 | O(n) | O(1) | 有序数组操作 |
| 滑动窗口 | O(n) | O(1)~O(k) | 子数组/子串问题 |

## 推荐学习顺序

1. 遍历技巧 — 掌握基础操作
2. 前缀和 — 学习预处理思想
3. 差分数组 — 区间操作利器
4. 字符串匹配 — 经典算法入门
5. 双串问题 — 综合应用
