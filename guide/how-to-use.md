# 使用指南

## 页面结构

每个算法主题页面都遵循统一的结构：

### 顶部导航
- **首页** — 回到主页面
- **算法主题** — 下拉菜单列出全部 16 个主题
- **使用指南** — 当前页面
- **快速开始** — 学习路径推荐

### 左侧边栏
显示当前主题下的全部子主题，方便快速跳转。

### 内容区域

#### 主题概述页（`/topics/<主题>/`）
- 核心概念与定义
- 该主题的解题思路框架
- 复杂度总览表
- 子主题导航链接

#### 子主题页（`/topics/<主题>/<子主题>`）
- 概念讲解
- 关键技巧
- LeetCode 原题列表（含难度标签）
- 代码示例（Python / Java / C++）
- 复杂度分析
- 相关推荐

## 如何高效使用

### 方法一：系统性学习
按照[快速开始](/guide/getting-started)推荐的学习路径，逐个主题循序渐进。

### 方法二：按需查阅
在面试准备中遇到不熟悉的题型时，直接通过侧边栏或搜索找到对应主题。

### 方法三：专项突破
针对薄弱环节，集中练习一个主题下的所有子主题和配套题目。

## 题目标注说明

每道 LeetCode 题目包含以下信息：

```
[题号] · 题目名称
难度标签
推荐标签（如：高频面试题、经典必做题）
解题思路概要
复杂度分析
```

### 难度标签含义

| 标签 | 颜色 | 含义 |
|------|------|------|
| <span class="difficulty-easy">简单</span> | 绿色 | 适合新手，考察基础知识 |
| <span class="difficulty-medium">中等</span> | 橙色 | 面试高频，需熟练掌握 |
| <span class="difficulty-hard">困难</span> | 红色 | 进阶挑战，考察综合能力 |

## 搜索功能

点击页面顶部的搜索图标（🔍）或按 `Ctrl+K`（Windows）/ `Cmd+K`（Mac）即可搜索全站内容。

## 主题切换

点击页面右上角的 🌙/☀️ 图标可在深色模式和浅色模式间切换。
