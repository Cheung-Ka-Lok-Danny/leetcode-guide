# 关于本站

**LeetCode 算法题指南** 是一个面向算法学习者和技术面试候选人的系统性学习资源。

## 项目缘起

LeetCode 上有超过 3000 道题目，初学者往往面临"不知从何刷起"的困境。本指南的目标是：

- **按主题分类** — 将散落的题目归类到算法主题下，形成知识体系
- **由浅入深** — 每个主题从基础概念到进阶技巧，层层递进
- **直击本质** — 深入讲解算法思想，而非单纯提供题解

## 内容结构

- **16 大算法主题**：涵盖数组、链表、树、图、动态规划等面试高频考点
- **72 个子主题**：每个主题分解为 3-6 个子主题，逐一深入
- **300+ 道 LeetCode 原题**：附编号、难度标签和官方链接

## 技术栈

- **框架**：[VitePress](https://vitepress.dev/) — Vue 驱动的静态站点生成器
- **语言**：Python（代码示例）/ Vue 3 / Markdown
- **部署**：GitHub Pages
- **搜索**：VitePress 内置离线搜索
