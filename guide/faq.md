# 常见问题

## 基础问题

### 这个指南适合什么基础的人？
本指南从最基础的数组、字符串开始，逐步深入到动态规划、图等进阶主题。建议至少掌握一门编程语言的基础语法（变量、循环、函数）。

### 需要按照什么顺序学习？
建议按照[快速开始](/guide/getting-started)推荐的路径：
1. **基础篇**：数组与字符串 → 链表 → 栈与队列 → 哈希表 → 排序与搜索
2. **核心篇**：树与二叉树 → 堆 → 双指针 → 滑动窗口 → 回溯算法
3. **进阶篇**：动态规划 → 贪心算法 → 图 → 并查集
4. **专项技巧**：位运算 → 数学技巧

### 每个主题需要花多长时间？
每个主题的概述页约 15-30 分钟阅读理解，子主题页每页约 30-60 分钟（含刷题练习）。

## 内容问题

### 代码示例用什么语言？
目前所有代码示例使用 **Python 3**。Python 语法简洁、可读性强，适合快速理解算法思路。

### 题目的难度等级怎么看？
- <span class="difficulty-easy">简单 Easy</span> — 基础题，适合入门
- <span class="difficulty-medium">中等 Medium</span> — 核心题，面试高频
- <span class="difficulty-hard">困难 Hard</span> — 挑战题，拔高训练

### 题目链接打不开怎么办？
所有题目链接指向 **LeetCode 中国官网**（leetcode.cn）。如果访问困难，可以尝试切换网络或使用 LeetCode 国际站（leetcode.com），搜索对应题号即可。

## 技术问题

### 如何在本地运行本站？
```bash
cd leetcode-guide
npm install
npm run dev
```

### 如何部署到自己的服务器？
```bash
npm run build
# 将 .vitepress/dist 目录部署到任何静态托管服务
```

### 如何贡献内容？
本站采用 Markdown 格式编写，你可以在 GitHub 上提交 Pull Request 来贡献内容或修复错误。
