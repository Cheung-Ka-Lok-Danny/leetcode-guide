# 贪心算法

贪心算法（Greedy Algorithm）在每一步都选择当前最优的决策，期望通过局部最优达到全局最优。

## 核心概念

- **贪心选择性质**：局部最优能推导出全局最优
- **最优子结构**：问题的最优解包含子问题的最优解
- **与DP的区别**：贪心不能回退，DP会保存所有子问题结果
- **适用场景**：区间问题、分配问题、图论中的最小生成树

## 贪心算法设计步骤

1. **将问题转化为**：对一组候选对象做选择的问题
2. **确定贪心策略**：定义"当前最优"的标准
3. **证明正确性**：交换论证法或归纳法
4. **实现并验证**：编写代码并测试边界
